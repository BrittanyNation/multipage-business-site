# PureNest Cleaning — Multi-Page Business Website

A complete multi-page small-business website for **PureNest Cleaning**, a fictional cleaning company with fresh mint-and-white branding — friendly, trustworthy, and easy to book.

**Live demo:** https://brittanynation.github.io/multipage-business-site/

## Roles this project supports

- Website Designer
- Webflow Designer
- Web Designer
- Front-End Designer

## What it demonstrates

- **Full multi-page site architecture** — Home, Services, About, Blog index, a full sample Blog Post, and Contact / Booking, with consistent header, navigation, and footer across every page
- **Consistent branding** — a contrast-safe mint accent on white with dark text, one type system, reusable cards, badges, buttons, and call-to-action bands
- **Content templates** — service tiers with what's-included checklists and sample pricing, testimonial and service-area sections, blog cards with categories and excerpts, and a reusable article template (`post.html`)
- **Conversion-focused layout** — hero with booking CTA, how-it-works steps, trust/safety notes, and a booking form with service, date, home-size, and pet fields
- **Responsive, accessible basics** — mobile-first CSS, collapsible navigation with `aria-expanded`, skip link, labels on every form field, visible focus states, semantic HTML, and active-page highlighting
- **The shape of a Webflow client build** — the page structure, content blocks, and CMS-style blog layout a designer would build in Webflow for a real local-service client

## Workflow note

My real design workflow runs in **Sketch and Webflow** — I design and build client sites visually in those tools. This demo is hand-built in HTML/CSS (with a small amount of JavaScript for the mobile nav and the demo form thank-you message) so the work can be reviewed directly on GitHub.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home — hero, services snapshot, how it works, testimonials, service area, CTA |
| `services.html` | Service tiers with checklists and starting prices (labeled sample pricing) |
| `about.html` | Story, values, generic team (initials avatars, no fake-person photos), trust & safety |
| `blog.html` | Blog index — 6 article cards with categories and excerpts |
| `post.html` | One full sample article showing the content template |
| `contact.html` | Contact / booking form (front-end only; demo form does not submit) |
| `styles.css` | Shared stylesheet |
| `app.js` | Mobile nav toggle + form thank-you message |
